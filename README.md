一个小工具，可以在悬浮的界面中实时显示当天的累计学习时间和娱乐时间，效果如下图

<img width="255" height="178" alt="image" src="https://github.com/user-attachments/assets/9509db49-1448-4e89-85c6-c78aba4db5c3" />

通过抓取当前运行的窗口的名称实现，可以自行设置关键词匹配。界面左下角显示的是当前抓取到的软件/网站名称，鼠标移动到上面时可显示完整内容，帮助正确设置关键词。下图是我在编辑此文档时抓取的窗口名称，作为一个例子：

<img width="262" height="247" alt="image" src="https://github.com/user-attachments/assets/8781948d-d2cb-4288-89ab-8f7fa5d81edb" />

设置界面中的关键词匹配（可自行删改）：

<img width="388" height="596" alt="image" src="https://github.com/user-attachments/assets/23cbaf92-eb9f-471b-831c-91551aa4ecd2" />

此外还可以看出，设置界面中还可设置是否开机自启动、每日目标、每日更新数据的时间，每日目标决定了进度条的总长度，从而通过进度条可直观查看目标实现状况。

统计界面可显示时间轴、统计数据及近七天折线图，如图

<img width="885" height="542" alt="image" src="https://github.com/user-attachments/assets/e481e4a9-aad3-4659-99f2-bd5d8ea3eec2" />

可以看到时间轴、统计数据等都是从自己设置的时间作为一天起点。上图中由于开发者还未运行足够长时间，因而没能展示出完整的折线图

此外双击界面还可以最小化（再次双击可以复原），最小化后变为一个很窄的显示条，只显示当前状态及对应的进度条，如图：

<img width="261" height="37" alt="image" src="https://github.com/user-attachments/assets/f56df0b4-a3d9-4836-a030-936a49386491" />

最小化后的界面可做到几乎不影响屏幕显示内容的观感，同时想查看时又不至于难以找到
